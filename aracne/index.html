Conecta el panel con tu repositorio

Las ofertas están en un repositorio privado. Este panel las lee directamente de GitHub con un token que solo vive en este navegador. La página no contiene ningún dato.

  1. Abre crear token (fine-grained).
  2. Repository access: Only select repositories → C10N67/aracne.
  3. Permissions → Repository → Contents: Read and write. Con Read-only podrás ver las ofertas, pero no marcarlas.
  4. Opcional, para lanzar la búsqueda desde aquí: Permissions → Repository → Actions: Read and write.
  5. Genera el token y pégalo aquí.

Para borrarlo de este navegador, pulsa Desconectar. Para anularlo del todo, revócalo en GitHub.
